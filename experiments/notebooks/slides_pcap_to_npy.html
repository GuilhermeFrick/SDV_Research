Implementação · Parser

Funções do Parser de PCAPs

parse_someip(raw: bytes) → dict

def parse_someip(raw):
    # Desempacota 16 bytes do header (big-endian)
    svc, mth, length = struct.unpack_from('>HHI', raw, 0)
    cli, sess        = struct.unpack_from('>HH',  raw, 8)
    pver, iver       = struct.unpack_from('>BB',  raw, 12)
    mtype, rcode     = struct.unpack_from('>BB',  raw, 14)
    payload = raw[16:]           # bytes após o header
    return {
        'service_id':         svc,
        'is_sd':              svc == 0xFFFF,  # SOME/IP-SD
        'someip_payload_hex': payload[:32].hex(),
        'someip_payload_len': len(payload),
        # … client_id, session_id, msg_type, return_code
    }

parse_packet(pkt, label, pcap_file) → dict

def parse_packet(pkt, label, pcap_file):
    # Camada IP
    ip = pkt[IP]            # src/dst/ttl/len/id/flags
    # Camada de transporte
    if pkt.haslayer(TCP):
        rec = {transport: 'TCP', src_port, dst_port, …}
    elif pkt.haslayer(UDP):
        rec = {transport: 'UDP', src_port, dst_port, …}
    # Filtra por porta SOME/IP (30490–30510)
    if not is_someip_port(src_port, dst_port):
        return None
    # Captura payload de transporte ANTES do parse SOME/IP
    rec['transport_payload_hex'] = raw[:32].hex()
    # Parse do header SOME/IP
    sh = parse_someip(raw)
    if sh:
        rec.update(sh)
    return rec

Implementação · Modelo de Bytes

Modelo de Distribuição de Bytes — ByteModel

Conceito: distribuição de bytes por posição

Para cada posição i do payload (até 256 bytes), o modelo aprende a probabilidade de cada valor de byte b ∈ [0, 255] sob tráfego benigno.

Usado como referência para quantificar o quanto um payload desvia do padrão normal — anomalia = payload de baixa probabilidade.

Equações implementadas

# Equações 2–3: contagem com Laplace smoothing (α = 1)
P[i, b] = (count[i,b] + α) / (N_i + 256·α)

# Equação 5: log-likelihood (quanto mais negativo → mais anômalo)
LogL(x) = Σ log P[i, x_i]    para i = 0…len(x)

# Equação 6: cross-entropy normalizada por L
H(x) = -(1/L) · Σ log P[i, x_i]   (L = len(x))

Classe ByteModel — interface

MétodoDescrição
fit(payloads_hex) Aprende distribuição P[i,b] a partir de hex strings benignas
log_likelihood(h) Score escalar — quanto mais negativo, mais anômalo
cross_entropy(h) Entropia normalizada — comparável entre payloads de tamanhos diferentes

hamming(h_a, h_b) → float

Distância de Hamming bit-a-bit entre dois payloads consecutivos no mesmo fluxo.

# Equação 7: conta bits diferentes via XOR + popcount
def hamming(h_a, h_b):
    a, b = bytes.fromhex(h_a), bytes.fromhex(h_b)
    L = min(len(a), len(b))
    diff = np.bitwise_xor(a[:L], b[:L])
    return np.unpackbits(diff).sum()

0 = payloads idênticos (tráfego periódico normal)
alto = payload muito diferente do anterior (possível ataque fuzzy/mitm)

Por que 3 modelos separados?

SOME/IP regular, SOME/IP-SD e TCP/UDP têm estruturas de bytes radicalmente diferentes. Um modelo único seria muito genérico. Kim et al. treinam um modelo por tipo para maximizar a discriminabilidade de anomalias específicas de cada camada.
