Etapa 1 — Parse dos 7 PCAPs → parsed_packets.csv

parse_someip(raw: bytes) → dict

def parse_someip(raw):
    # Desempacota 16 bytes (big-endian, Eq. AUTOSAR)
    svc, mth, length = struct.unpack_from('>HHI', raw, 0)
    cli, sess        = struct.unpack_from('>HH',  raw, 8)
    pver, iver       = struct.unpack_from('>BB',  raw, 12)
    mtype, rcode     = struct.unpack_from('>BB',  raw, 14)
    payload = raw[16:]
    return {
        'service_id':         svc,
        'is_sd':              svc == 0xFFFF,
        'someip_payload_hex': payload[:32].hex(),
        # … client_id, session_id, msg_type, return_code …
    }

parse_packet(pkt, label) → dict | None

def parse_packet(pkt, label, pcap_file):
    if not pkt.haslayer(IP): return None
    ip = pkt[IP]                         # src, dst, ttl, len …
    if pkt.haslayer(TCP):
        rec['transport'] = 'TCP'          # seq, ack, flags
    elif pkt.haslayer(UDP):
        rec['transport'] = 'UDP'
    else: return None
    if not is_someip_port(sp, dp): return None
    # Captura payload antes do parse SOME/IP
    rec['transport_payload_hex'] = raw[:32].hex()
    sh = parse_someip(raw)
    if sh: rec.update(sh)
    return rec

Etapa 2 — Modelos de Distribuição de Bytes (ByteModel)

Intuição: o que é "tráfego normal"?

Para cada posição i do payload (até 256 bytes), o modelo aprende qual byte b ∈ [0, 255] é mais provável no tráfego benigno.
Um payload de ataque tende a ter bytes de baixa probabilidade → score anômalo.

Equações implementadas

# Equações 2–3: Estima a probabilidade de cada byte em cada posição do payload.
# O Laplace smoothing (α = 1) evita probabilidades zero para bytes nunca vistos
P[i, b] = (count[i, b] + α) / (N_i + 256·α)

# Equação 5: Mede o quão provável um payload é dentro do padrão aprendido, log-likelihood (mais negativo → mais anômalo)
LogL(x) = Σ log P[i, x_i]    para i = 0…len(x)

# Equação 6: Mede o nível de imprevisibilidade do payload
H(x) = -(1/L) · Σ log P[i, x_i]    L = len(x)

hamming(h_a, h_b) → float

Distância de Hamming bit-a-bit entre payload atual e anterior no mesmo fluxo (Eq. 7). Valores próximos de 0 indicam mensagens muito similares, enquanto valores altos indicam mudanças significativas no conteúdo.

def hamming(h_a, h_b):
    a, b = bytes.fromhex(h_a), bytes.fromhex(h_b)
    L = min(len(a), len(b))
    diff = np.bitwise_xor(a[:L], b[:L])
    return np.unpackbits(diff).sum()
# 0 = idênticos · alto = payload muito diferente

Etapa 3 — Extração das 12 Features por Fluxo

# Feature Categoria Como é calculada
f01 IP time interval Tempo Δt entre pacotes no mesmo fluxo (five-tuple)
f02 SOME/IP likelihood Likelihood LogL(someip_payload) — model_someip benigno
f03 SOME/IP-SD likelihood Likelihood LogL(someip_payload) — model_someip_sd benigno
f04 TCP/UDP likelihood Likelihood LogL(transport_payload) — model_tcpudp benigno
f05 SOME/IP entropy Entropy H(someip_payload) normalizada por len
f06 SOME/IP-SD entropy Entropy H(someip_payload_sd) normalizada por len
f07 TCP/UDP entropy Entropy H(transport_payload) normalizada por len
f08 SOME/IP payload changes Changes Hamming(prev_si, si_atual) — só is_sd=False
f09 SOME/IP-SD payload changes Changes Hamming(prev_sd, sd_atual) — só is_sd=True
f10 TCP/UDP payload changes Changes Hamming(prev_tu, tu_atual) — todos os pacotes
f11 IP length changes Length Δ ip_len entre pacotes consecutivos no fluxo
f12 TCP/UDP length changes Length Δ transport_len entre pacotes consecutivos no fluxo

Sem data leakage — parâmetros do treino no teste

Os valores de min e max são aprendidos apenas no conjunto de treino e aplicados diretamente ao teste. Valores fora do intervalo são clipados para [0, 1].
